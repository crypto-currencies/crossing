# Image credits

The public [attribution page](/attributions) is generated from `content/attributions.ts` — that file is the source of record, not this doc. Add future visual credits there so their source, permission, restriction, and credit details appear consistently. Everything below is just a quick index for humans browsing the docs folder.

All images are Unsplash photos used under the [Unsplash License](https://unsplash.com/license): free for commercial and non-commercial use, no permission or attribution required, but they can't be resold unmodified or compiled into a competing stock-photo service. We credit anyway because it's the right thing to do.
